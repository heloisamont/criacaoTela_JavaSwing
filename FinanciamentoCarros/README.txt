FINANCIAMENTO DE CARROS - JAVA SWING

Como abrir no IntelliJ IDEA:

1. Extraia o arquivo ZIP.
2. Abra o IntelliJ IDEA.
3. Clique em File > Open.
4. Selecione a pasta "FinanciamentoCarros".
5. Certifique-se de que um JDK esteja configurado no projeto.
6. Abra:
   src > FinanciamentoCarros.java
7. Clique no botão Run (▶).

Requisitos:
- Java/JDK 8 ou superior.
- Não utiliza bibliotecas externas.

A aplicação contém:
- Marca (JComboBox)
- Modelo (JTextField)
- Ano de 2026 até 2000
- Valor do veículo
- Novo/Usado (JRadioButton)
- Dados adicionais para veículo usado
- Possui entrada? (JCheckBox)
- Entrada
- Parcelas: 12, 24, 36, 48 e 60
- Botão Calcular
- Botão Limpar
- Validações
- Resultado do financiamento

A taxa está configurada como 32%, pois reproduz o exemplo do protótipo:
R$ 45.000,00 financiados em 36 parcelas = R$ 59.400,00 no total e R$ 1.650,00 por parcela.
